Компоненты нужно использовать так:
- сначала использовать существующие компоненты из `frontend/components/ui`;
- если нужного компонента там нет, брать его из `shadcn`;
- если в `shadcn` нет нужного функционала, по возможности взять оттуда базовый компонент и на его основе сделать свой в `frontend/components/ui/custom`;
- если подходящей базы в `shadcn` нет, написать свой компонент на `TAILWIND`.
